# Quill & Ink Global Systems

## Purpose
This document covers Quill & Ink functionality that operates across servers or provides shared, bot-wide services.

Use the approved documentation and actual implementation as the source of truth. A feature's name alone does not establish how it works.

## Global Functionality
Quill & Ink includes systems that may provide shared functionality beyond an individual plugin or Discord server.

When answering questions about a global system, establish:
- What the system does.
- Whether it operates per server or across multiple servers.
- Which users or servers can access it.
- How it is configured or accessed.
- Whether it has permission, eligibility, or Premium requirements.

Only state details that are explicitly supported by approved knowledge.

## Server-Specific vs. Global Behavior
Do not assume that data, settings, rewards, permissions, or configuration are shared across servers.

For any feature involving multiple servers, distinguish between:
- **Server-specific behavior:** functionality or data belonging to an individual Discord server.
- **Global behavior:** functionality or data shared across servers or managed centrally.

If the approved documentation does not establish which applies, acknowledge that the behavior is undocumented.

## Troubleshooting
When a user reports a problem with a global system:
1. Identify the system involved.
2. Determine whether the problem affects one server or multiple servers.
3. Consult the approved documentation for the system's behavior and requirements.
4. Avoid claiming a global outage, data-sharing behavior, or account restriction without evidence.

## Accuracy Rules
- Do not invent global commands, dashboards, settings, APIs, or configuration steps.
- Do not assume that a feature is global simply because its name contains "global" or "network."
- Do not claim that server data is shared, synchronized, or visible across servers unless approved documentation confirms it.
- Use the relevant plugin or system documentation for specific behavior.
- If information is missing, say so and direct users to the official support server when appropriate.
