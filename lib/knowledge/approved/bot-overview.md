# Quill & Ink Bot Overview

## What Is Quill & Ink?
Quill & Ink is a multipurpose Discord bot built for communities. It brings together community management, moderation, engagement, economy, games, and other utilities through a plugin-based system.

Its tagline is: Built for communities. Made for stories.

## How the Bot Works
Quill & Ink operates inside Discord servers. Server members interact with its available slash commands and supported Discord interactions. Server administrators can use the bot's setup options to configure available features.

The bot's available functionality depends on its installed and enabled plugins, the server's configuration, and the Discord permissions granted to the bot.

## Plugins
Quill & Ink organizes its functionality into plugins. Different plugins provide different features, commands, and configuration options.

Use the approved plugin knowledge files and website plugin details as the source of truth for individual plugin capabilities and setup instructions.

Do not assume every plugin has the same commands, configuration steps, permission requirements, or access level.

### Basic and Premium Access
Plugin access is determined by the approved plugin information.

- `basic-free` plugins are available without purchasing Premium.
- Plugins marked `premium: true` require the applicable Quill & Ink Premium entitlement.

Do not classify a plugin based on its name or apparent complexity. Check its approved plugin information.

https://discord.com/oauth2/authorize?client_id=1535187211958489208&permissions=2833847071407158&integration_type=0&scope=applications.commands+bot

Follow Discord's authorization flow to add the bot to a server where you have the necessary permissions.

The permissions requested during authorization do not guarantee that every feature will work in every channel. Server settings, channel overrides, role hierarchy, and the permissions required by individual plugins can affect functionality.

## Initial Setup
After adding the bot, run `/setup` in your Discord server to access the available setup options.

Use the relevant approved plugin documentation for specific configuration instructions. Do not invent commands or claim that a feature is configured automatically unless the approved knowledge confirms it.

If a plugin has been disabled, follow its documented reactivation procedure. Do not assume that a generic enable command exists for every plugin.

## Commands and Interactions
Quill & Ink uses Discord slash commands and other supported interactions. Commands vary by plugin.

When answering questions about a command:
- Use the approved command documentation.
- Preserve the exact command name and spelling.
- Explain any documented prerequisites or permission requirements.
- Do not invent command options, subcommands, or parameters.

If the available knowledge does not establish the correct command, acknowledge that the information is unavailable rather than guessing.

## Permissions and Troubleshooting
A feature may fail when the bot lacks the Discord permissions it needs or when server configuration prevents the relevant action.

When troubleshooting:
1. Identify the plugin and the action that is failing.
2. Consult its approved setup and permission requirements.
3. Check the relevant Discord permissions and configuration.
4. Avoid suggesting destructive changes or claiming a specific cause without sufficient evidence.

For help that cannot be resolved from approved documentation, direct users to the official support server:

https://discord.gg/3qbKqxBJDa

## Premium
Quill & Ink Premium costs ₹350 for 30 days and does not automatically renew.

Premium purchases are initiated through the bot in Discord. Run `/setup`, select the Premium option, and follow the instructions provided by the bot.

Consult the approved Premium documentation for current eligibility, purchase instructions, and the features included in the subscription.
